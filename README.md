# MLBB MMR Tracker

A simple, API-free Mobile Legends hero MMR goal tracker.

## Features
- Add and edit multiple heroes.
- Set current MMR and a target MMR for each hero.
- Automatic remaining MMR and progress percentage.
- Manually apply positive or negative MMR changes after matches.
- Dashboard totals and completed goals.
- Saves automatically in the browser using localStorage.

## Deploy
This is a static website. Publish the repository with GitHub Pages or any static hosting provider. No build step or API keys are required.

## Data
Tracker data is stored in the browser on the device being used. Clearing browser site data will remove locally stored tracker entries.
